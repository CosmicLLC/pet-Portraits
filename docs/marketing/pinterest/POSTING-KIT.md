Pin builder (already logged in as PawMasterpiece): https://www.pinterest.com/pin-creation-tool/

## How to post each pin (6 steps)
1. Click **Choose a file** in the pin builder and pick the **Image file** listed (they live in `docs\marketing\pinterest\generated\`).
2. Copy the **Title** line into the Title field.
3. Copy the **Description** block into the Description field.
4. Copy the **Link** into the Link field.
5. Set **Board** to the one named in the heading (create it the first time you use it).
6. Click **Publish**. Repeat. Each value is on its own line so you can triple-click to select it cleanly.
